Verify the credential, not just the claim.

An administrator manually checks a clinician's licence before they can treat a patient. This console prototypes that workflow with security built into every step: hashed sessions, validated uploads, role-gated actions, and a tamper-evident audit trail — not bolted on afterward.

This app never writes user text into the DOM with innerHTML. Notes are inserted with textContent, so markup and scripts are displayed as literal characters instead of running — the standard defense against stored/reflected XSS.

Verification queue

Actions are gated by role. Switch the role selector in the sidebar and watch which buttons stay enabled — this is role-based access control (RBAC) enforced at the UI, mirroring checks that must also live on the server.

Tamper-evident audit chain

Every sensitive action is logged with a hash of the previous entry baked in — like a mini blockchain. Change one historical entry and the chain visibly breaks.
